# PROJECT GENESIS v26.11.5 — code and data for *GENESIS CONVIVIUM 100*

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24092709.svg)](https://doi.org/10.5281/zenodo.24092709)

**GENESIS CONVIVIUM 100: The Human–AI Civilization Experiment** is a century-scale, agent-based
*computational thought experiment* about how a growing machine-capability advantage could turn
into economic and political power, and what that would do to human welfare, human agency,
human–AI coexistence and the biosphere.

This repository holds the simulation (PROJECT GENESIS v26.11.5), the exact data behind the
working paper (revision 5, November 2026), and the scripts that regenerate every figure and
table in it.

> **This is not a forecast.** Every number is the output of a constructed model with
> author-chosen parameters. Nothing here is a probability of a real-world event. The twelve
> "actors" (United States, China, Iran, …) are parameter sets in a toy world; their simulated
> trajectories say nothing about what real countries, governments or people will do. "AGI",
> "ASI", "domesticated", "AI-enabled tyranny" and similar terms are names of thresholds defined
> in the code. The model contains no operational information about weapons or military tactics.
> The work has not been peer-reviewed.

## What the model is

- 463 human agents and 119 AI agents in 12 abstract geopolitical actors, representing 6.335 billion people
- 1,200 monthly steps, November 2026 to October 2126
- tabular Q-learning for agents; rule-based institutions, elections and geopolitics; markets for
  energy, food and critical minerals; an AI capability, autonomy and (hidden) alignment process;
  demography, climate and biosphere proxies; annual government and AI decisions
- a matched-seed **Policy Lab** that applies 12 stylized interventions to identical worlds
- a live dashboard (in Colab or locally) and a static "Observatory" page

Dependencies of the simulation: NumPy and pandas. Nothing else.

## Quick start

```bash
pip install -r requirements.txt

# 1. Reproduce the paper's results: seed-42 main run + 8-seed Policy Lab (about 10 minutes, one CPU core)
python run_headless.py --out run_output

# 2. Check that your run matches the reference data
python analysis/check_reproduction.py run_output/genesis_out_v26115/genesis_v26.11.5_results.zip data/results_v26.11.5

# 3. Regenerate the figures and tables of the paper
python analysis/make_figures.py data/results_v26.11.5 figures data/policy_lab_extended
python analysis/make_tables.py  data/results_v26.11.5 tables  data/policy_lab_extended/policy_lab_runs_40seeds.csv
```

More Policy Lab seeds (this is how the 40-seed extension was produced):

```bash
python run_headless.py --lab-seeds 8:40 --lab-only --out out_ext
```

### In Google Colab

Upload `PROJECT_GENESIS_v26.11.5.ipynb`, choose a CPU runtime and *Runtime → Run all*. The live
dashboard opens in a new tab (Pause / Resume / Step 1 year / Intervene / Checkpoint / Restore /
Export). The notebook's markdown cells are in Romanian; code, dashboard and outputs are in English.

If the Colab account offers a built-in language model, the notebook can use it for decade
summaries and for a few "critical" decisions; every such decision is logged with its source.
**The published results did not use it** (all decisions are labelled `rules`, all summaries
`template`). Set `USE_COLAB_AI = False` in the first code cell to make sure a Colab run matches
the published data.

## Results in one paragraph

In the main run (seed 42), frontier AI capability crosses the model's AGI threshold at 2030.00
(this date is set by the growth parameters and is an input, not a finding) and AI systems hold a
majority of modelled resources from 2068.8. The human decision share falls from 98.8% to 18.2%
and the Human Welfare Index from 0.744 to 0.462, with no open human–AI conflict at any point. In
the Policy Lab, a global AI treaty has a small, consistent positive effect on coexistence and on
human welfare. The strongly negative averages that some interventions show with 8 seeds come
from a single low-alignment world and largely disappear with 40 seeds. Collapse of coexistence
occurs only in worlds with negative hidden alignment, and alignment research is the only
intervention under which no world ends in open conflict. Read the paper's Section 8 before
quoting any of this: the limitations are substantial.

## Reproducibility

Reference environment: Python 3.13.18, NumPy 2.5.3, pandas 3.0.5, Linux x86-64. Results are
deterministic for a given seed. The reference data were reproduced bit-for-bit on a second full
run of this repository, and they agree with the tables of the earlier manuscript revision, which
was produced in a different environment. Bit-identical results on other library versions or
processors are likely but not guaranteed (floating-point arithmetic).

The notebook also runs ten acceptance tests on every execution (checkpoint determinism,
population accounting, index bounds, and so on); a run aborts if one fails.

## Security note for the live dashboard

The dashboard's HTTP endpoints (pause, intervene, restore checkpoint, export) have no
authentication. They listen on `127.0.0.1` only. Do not expose ports 8771/8772 to a network.
Checkpoints are Python pickles: only restore checkpoint files you created yourself.

## Known limitations

See `CHANGELOG.md` ("Known issues") and Section 8 of the paper. In short: no external validity,
hand-chosen parameters, no sensitivity analysis yet, few seeds, endpoint metrics, saturating
indices and an unresolved food-supply artefact for two actors.
